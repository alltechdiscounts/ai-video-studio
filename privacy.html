AI Video Studio is a personal tool used by its owner. It connects to the owner's own TikTok account via TikTok Login Kit to upload videos the owner created.

Data we access

Basic profile information and permission to upload videos, only for the owner's account, only after the owner authorizes it.

Storage

Access tokens are stored locally on the owner's computer. No data is sold, shared with third parties or stored on any server operated by us.

Revoking access

Access can be removed at any time from TikTok settings (Security and permissions, Apps) or by deleting the local token file.
